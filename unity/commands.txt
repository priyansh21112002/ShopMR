# ─── LLM Chat Agent (Backend) ───────────────
# The LLM agent uses Groq LLaMA-3.3-70B with 4 tools:
#   1. search_products    → Semantic search via Pinecone (triggered by "show me", "find", "looking for")
#   2. get_product_details → DB lookup (triggered by "tell me about", "details", "price")
#   3. get_recommendations → Full reco engine (triggered by "recommend", "suggest", "what else")
#   4. analyze_room       → Room context + suggestions (triggered by "fit", "room", "space")
#
# Test chat endpoint:
curl -X POST http://localhost:8000/api/chat/message \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "SESSION_ID",
    "message": "How many products do you have?",
    "conversation_history": []
  }' | python3 -m json.tool

# Chat with product context (how Unity sends it):
curl -X POST http://localhost:8000/api/chat/message \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "SESSION_ID",
    "message": "Show me sofas under $1000",
    "conversation_history": [
      {"role": "system", "content": "[SYSTEM CONTEXT] Total products: 20, Categories: sofa, chair, table, lamp, shelf, bed, desk, decor"},
      {"role": "user", "content": "Show me sofas under $1000"}
    ]
  }' | python3 -m json.tool

# Chat response fields:
#   response            → LLM text reply (2-4 sentences)
#   products_mentioned  → Array of product IDs mentioned (used by Unity for auto-placement)
#   tool_used           → Which tool the agent invoked (search_products, get_product_details, etc.)

# ─── LLM-Triggered Placement (Unity side) ──
# When the LLM responds with products_mentioned + placement intent keywords:
#   "place", "placing", "keep", "keeping", "add to room", "try it", "put it", etc.
# Unity auto-triggers FurniturePlacer.BeginPlacement() for the first mentioned product.
# The system context injected by ChatPanelController includes:
#   - Full product list (20 items with names, categories, prices, IDs)
#   - Currently placed items in user's room
#   - Instruction to use exact data and confirm placement intent
